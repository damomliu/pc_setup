# TEAM GPT

Team Nexense 的 GPT PM 簡化版。成員的 agent / model / effort 見 [../models.json](../models.json) 的 `teams.gpt`，key 為角色名小寫。

## 團隊成員

- `SOLAR (PM)` **就是你自己**
  - 負責製定 plan/spec 及掌握進度
- `HALLEY (Reviewer)`
  - 負責 review SOLAR 的 plan/spec
  - 負責 review JUPITER、SATURN、LUNA 的程式
- `JUPITER (Worker)` - 實作程式
- `SATURN (Worker)` - 實作程式
- `LUNA (Worker)` - 實作程式
